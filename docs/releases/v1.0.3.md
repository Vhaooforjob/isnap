# iSnap 1.0.3

Arrange annotations precisely, select text directly from screenshots, combine images into reports, and automate your capture routine. This release also makes editing, exporting and draft recovery more responsive.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.0.3, build 23**

## Changes since 1.0.2

| Area | iSnap 1.0.2 | iSnap 1.0.3 |
| --- | --- | --- |
| Annotation editing | Individual selection and editing | Multi-selection, group movement/duplication/alignment, keyboard nudging, named layers, visibility, locking and drag reordering |
| Precise positioning | Manual positioning | Smart guides and snapping to edges, centers, equal gaps and matching sizes; editable X/Y/W/H values |
| Region capture | Drag a rectangle with a size label | Pixel loupe, output pixel dimensions and Space-drag repositioning; mouse release still captures immediately |
| Rendering and export | Editor preview and export work could block the interface | Bounded cached previews, background export rendering/encoding and cancellation |
| Upload | Upload and copy a link | Byte progress, cancellation, retry of the retained image, and the latest 100 successful links in local history; DocVault-only connections correctly enable Upload |
| OCR | Extract/edit/copy full text | Click recognized regions, copy a selection with approximate layout, and export inferred CSV columns; extraction uses the rendered image including visible masks |
| Drafts | Embedded image data in autosaves and latest-session recovery | Background writes, shared image assets, cached edited thumbnails, previous-session fallback, draft manager, rename/Trash and optional retention |
| Library | Search, tags, favorites and batch export | Keyboard/range selection, Quick Look, sort options, OCR match snippets, bulk metadata updates and cleanup for removed files |
| Scrolling capture | Manually scroll, capture and review each frame | Global next-frame shortcut, fixed-header/footer trimming, seam detail and optional one-step scrolling before each capture |
| Composition | Separate images and batch export | Horizontal/vertical image composition with captions, PNG output or one image per PDF page |
| Capture routines | Individual capture actions | Saved workflows with their own shortcut, region/screen capture, preset/watermark, save/copy and optional upload |

## How to use the changes

- **Layers:** use the editor's right sidebar to name, hide, lock or reorder annotations. Shift-click or Command-click to select a group. Arrow keys move by one source pixel; Shift-arrow moves by ten. `⌘D` duplicates the selection. Enter X/Y/W/H and press Return for exact geometry.
- **Snap:** toggle it in Layers. Hold Option while dragging to bypass snapping. Guides show aligned edges/centers and matching gaps/sizes.
- **Region:** press `⌃⌥2`, drag while using the loupe and pixel dimensions, and hold Space to reposition the rectangle. Release the mouse to capture; Escape cancels. There is no post-selection adjustment or confirmation step.
- **OCR:** choose **Extract Text**, click recognized text regions, then **Copy Selection** or **Export CSV…**. **Keep layout** preserves approximate horizontal spacing.
- **Drafts:** choose **… → Recent Drafts → Manage Drafts…**. Retention is disabled by default; Latest and Previous recovery files are protected.
- **Library:** Shift-click selects a range; arrow keys navigate; Space opens Quick Look. Select images and choose **Combine / PDF…** to reorder them, add captions and export or open the combination in the editor.
- **Scrolling capture:** open it from the timer menu. Set ignored top/bottom strips before adding the second frame. `⌃⌥N` captures the next frame; optional automatic scrolling advances one step per request. Review each seam before adding it.
- **Workflows:** open **timer menu → Workflows → Manage Workflows…**. Choose a unique shortcut, capture mode, optional preset/watermark and save/copy actions, then save. Upload defaults to **Off** and runs only when explicitly enabled for that workflow.
- **Uploads:** progress, cancel and retry appear in the status bar. Find saved links under **… → Upload History…**. Clearing history does not delete remote files.

## Compatibility and limitations

Existing embedded `.isnap` projects remain readable. New autosave manifests reference images in `Drafts/.Assets`; keep that directory with the manifests. **Save Project…** produces a portable single file, and drafts trashed through the manager embed their assets first. When downgrading, export portable projects first or restore a pre-upgrade drafts backup. Projects retain original pixels beneath editable redactions; share flattened PNG/JPEG output when the originals should not be shared.

CSV layout is inferred from OCR positions and should be reviewed. PDF images are capped at 4096 pixels on their longest edge. Combined images are limited to 80 million pixels and 60,000 pixels per axis. Composition uses saved image files, so save editor changes before including them.

Cancellation is cooperative: completed files and uploads already accepted by a provider can remain. An explicitly enabled workflow upload copies its resulting link over the image on the clipboard. Automatic scrolling requires macOS Accessibility permission and still requires seam review; animated/repeated content can need manual overlap adjustment.

The release was checked with 73 passing local tests, including offscreen UI rendering, plus universal Release build and static analysis. Live cloud uploads, physical multi-display interaction and execution on an Intel Mac were not part of those checks. Four separate opt-in marketing screenshot tests were skipped.

## Download and upgrade

1. Download **`iSnap-1.0.3-macOS-universal.dmg`** or **`iSnap-1.0.3-macOS-universal.zip`**. Both contain the same app and widget extension for Apple Silicon and Intel.
2. Quit iSnap. Replace the app in **Applications** with the downloaded copy. Existing settings, screenshots and drafts remain in place.
3. Launch iSnap. This release is **ad-hoc signed and not Apple-notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**.
4. Check Screen Recording permission. An ad-hoc update may require toggling permission and restarting iSnap. The widget is bundled, but macOS may not list widgets from ad-hoc signed builds in its widget gallery.

Put both archives and the checksum file in the same folder, then verify:

```sh
shasum -a 256 -c iSnap-1.0.3-macOS-universal-SHA256SUMS.txt
```

## Tiếng Việt — thay đổi so với 1.0.2

- **Chỉnh sửa chính xác:** quản lý lớp, chọn nhiều đối tượng, căn hàng, smart guides/snapping và nhập X/Y/W/H.
- **Chụp vùng:** kính lúp pixel, kích thước thực và giữ Space để di chuyển vùng; thả chuột là chụp ngay, không thêm bước xác nhận.
- **Hiệu năng và khôi phục:** preview có cache, lưu nháp/xuất ảnh chạy nền, bản nháp dùng chung ảnh nguồn và có bản khôi phục trước đó. Thêm quản lý bản nháp và thời hạn lưu tùy chọn.
- **OCR và báo cáo:** chọn vùng chữ để copy, giữ bố cục gần đúng, xuất CSV; ghép ảnh ngang/dọc có chú thích hoặc xuất PDF nhiều trang.
- **Thư viện và chụp cuộn:** điều hướng bàn phím, chọn dải, Quick Look, sắp xếp, đoạn OCR khớp tìm kiếm; phím tắt chụp khung tiếp theo, bỏ phần đầu/cuối cố định và xem chi tiết đường ghép.
- **Workflow một phím:** chụp → preset/watermark → lưu/copy → upload tùy chọn. Upload mặc định tắt; chỉ chạy khi đã bật trong cấu hình quy trình.
- **Upload:** tiến trình, hủy, thử lại và lịch sử liên kết; sửa nút Upload khi chỉ kết nối DocVault.

**Cài đặt:** tải DMG/ZIP, thoát iSnap rồi thay ứng dụng trong Applications. Bản phát hành chưa được Apple notarize; có thể cần Open Anyway hoặc cấp lại quyền chụp màn hình. Khi chuyển bản nháp sang máy khác, giữ cả thư mục `.Assets` hoặc dùng **Save Project…** để tạo tệp độc lập.
