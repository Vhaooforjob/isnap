# iSnap 1.0.5

Find tools faster, organize screenshots without losing their metadata, and turn long captures into searchable documents and step-by-step guides.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.0.5, build 25**

## Changes since 1.0.4

- **Command search:** press **⌘K** to find capture modes, editor tools and saved workflows using English or Vietnamese keywords, including unaccented Vietnamese. Navigate with arrow keys and Return.
- **Library organization:** collections, saved filters and quick tags; metadata survives same-volume file renames/moves. Rename images in the app, export/import metadata backups, and explicitly relink moved or restored files.
- **Duplicate review:** **Library → Metadata → Find Duplicate Files…** scans for identical file contents with progress and cancellation. Select files to review in Library before using its existing Trash confirmation. Nothing is selected or deleted automatically.
- **Long-image OCR and PDF:** recognition works across native-resolution tiles; PDF export supports searchable text and original-size, A4 or US Letter pages. OCR also reads QR payloads, with explicit opening of HTTP/HTTPS links.
- **Privacy review:** add keyword or regular-expression rules, preview suggested masks and choose matching phrases or whole lines. Matching runs off the interface thread with a processing budget.
- **Screenshot comparison:** select two images in Library to compare original pixels with synchronized viewing, zoom, tolerance and ignored areas. Export the difference as PNG.
- **Drawing and pixel tools:** smoothed freehand, highlighter, partial stroke eraser, saved annotation styles, magnifier callouts, pixel ruler and rendered-image color sampling.
- **Cut Out:** remove a horizontal or vertical strip and join the remaining image. Review any required flattening before applying; Undo restores editable layers.
- **Step guides:** open **… → Step Guide…**, capture/import steps, edit captions and reorder them, then export Markdown with images or PDF. **⌃⌥G** captures a step while the guide window is open.
- **Scrolling capture:** adds up/left/right directions, a visible Pause control and source-window/display checks that preserve captured frames when the source changes.
- **macOS Shortcuts:** actions for screenshot text extraction, preset/resize/export and saved capture workflows.

## Fixes and performance

Batch export decodes and renders at the requested output size while preserving canvas proportions. EXIF rotation now agrees with displayed dimensions. Thumbnail and comparison caches invalidate when files are replaced, ignored comparison regions are merged before pixel traversal, and stroke simplification no longer drops a pending branch. Canvas accessibility exposes named layers and keyboard actions.

The distribution pipeline supports configured Sparkle updates, Developer ID signing and notarization. **This release remains ad-hoc signed and uses the existing GitHub release notification; it does not enable automatic update installation.**

Local validation passed **122 tests with 0 failures and 4 opt-in marketing tests skipped**, including rendered checks of the enhanced workspace and new dialogs.

## Compatibility and limitations

- Existing workspace settings and projects remain readable. Metadata backups contain organization, not screenshot pixels. Cross-volume moves may require explicit relinking.
- Duplicate detection compares file bytes, not visual similarity. PNG/JPEG versions of the same picture may not form a group.
- Editable projects retain source images beneath privacy annotations. Share flattened PNG/JPEG/PDF exports when the underlying pixels must not be included.
- The step guide keeps one active draft; export it before creating a new guide. Cloud integrations remain inactive.
- OCR can make recognition errors. Dynamic scrolling pages, mixed-DPI displays, complete VoiceOver navigation and system-level Shortcuts execution still need broader device acceptance checks. See [validation](https://github.com/Vhaooforjob/isnap/blob/v1.0.5/docs/VALIDATION.md).
- The package is universal, but Intel hardware execution has not been tested. This distribution is **not Apple-notarized**. macOS may require Screen Recording/Accessibility permissions again; widgets may not appear for ad-hoc signed builds.

## Download and upgrade

1. Download **`iSnap-1.0.5-macOS-universal.dmg`** or **`iSnap-1.0.5-macOS-universal.zip`**.
2. Quit iSnap and replace it in **Applications**. Your Library, settings and drafts stay in place.
3. Launch iSnap. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**.
4. Check **Screen & System Audio Recording** (or **Screen Recording**) permission, and **Accessibility** for automatic scrolling. Restart the app if macOS requests it.

Verify downloaded files with the checksum manifest in the same folder:

```sh
shasum -a 256 -c iSnap-1.0.5-macOS-universal-SHA256SUMS.txt
```

## Tiếng Việt — thay đổi so với 1.0.4

- **⌘K tìm lệnh** bằng từ khóa Việt/Anh; gọi nhanh công cụ và workflow đã lưu.
- **Thư viện:** bộ sưu tập, bộ lọc, gắn thẻ nhanh, giữ metadata khi đổi tên/di chuyển cùng ổ đĩa, backup và liên kết lại ảnh.
- **Tìm file trùng:** quét có tiến độ/hủy; người dùng tự chọn và xem lại trong Thư viện trước khi xóa.
- **OCR ảnh dài, QR và PDF tìm kiếm được**, chia trang A4/Letter; xem trước vùng che theo từ/cụm hoặc cả dòng và quy tắc tùy chỉnh.
- **So sánh ảnh gốc:** zoom, ngưỡng sai lệch, vùng bỏ qua và xuất ảnh khác biệt.
- **Công cụ mới:** vẽ tự do, highlight, tẩy một phần nét, mẫu style, kính lúp, thước pixel, lấy màu và cắt bỏ dải giữa ảnh.
- **Hướng dẫn từng bước:** chụp bằng hotkey, chú thích, sắp xếp và xuất Markdown/PDF. Chụp cuộn thêm bốn hướng, Pause và kiểm tra cửa sổ nguồn.
- Thêm action **Shortcuts**; tối ưu xuất ảnh lớn, sửa xoay EXIF, cache ảnh và làm mượt nét.

**Cài đặt:** thay app trong Applications rồi kiểm tra quyền chụp màn hình/Trợ năng. Bản này ký ad hoc, chưa notarize và chưa bật tự động cài cập nhật. Dự án chỉnh sửa vẫn giữ ảnh gốc; dùng ảnh/PDF đã xuất khi chia sẻ nội dung đã che.
