# iSnap 1.0.4

A more compact editor, a stable empty Library layout, and quicker access to screenshots. Integrated cloud services move back to backlog and are unavailable in this release.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.0.4, build 24**

## Changes since 1.0.3

- **Compact inspector:** the Layers and canvas settings column starts at its minimum width of 280 points instead of taking roughly half the editor. Resizing the window gives additional space to the canvas; drag the divider to widen the inspector. Saved Presets and settings backgrounds now expand with the column. Image zoom and canvas inset defaults are unchanged.
- **Empty Library layout:** the capture toolbar stays at the top and the empty state fills the available content area, including when filters return no images.
- **Faster Library access:** **Screenshot Library** now sits directly beneath **Show iSnap** in the menu bar menu.
- **Cloud moved to backlog:** cloud settings, provider uploads, upload history, progress/retry controls and workflow upload choices are hidden. Startup connection checks, cloud credential reads from Settings, account refresh and upload entry points are disabled.
- **Existing workflows keep working locally:** saved cloud destinations are ignored; workflows still capture, apply styles, save and copy according to their settings. They no longer upload or replace the clipboard with a hosted link.

Local PNG/JPEG export and macOS sharing services, including AirDrop, Messages and Mail, remain available. Existing cloud configuration, Keychain credentials and local link history are retained but inactive. See the [cloud backlog](https://github.com/Vhaooforjob/isnap/blob/v1.0.4/docs/BACKLOG.md).

## Validation and limitations

The changed behavior was checked with 75 passing local tests, including offscreen rendering of the editor, resized inspector, empty Library, workflow editor and Settings. Four separate opt-in marketing screenshot tests were skipped. The universal Release build and static analysis passed.

The app and widget contain both arm64 and x86_64 code. Intel hardware execution was not tested. This distribution is **ad-hoc signed and not Apple-notarized**; macOS may require Screen Recording permission to be enabled again after replacing the app. The widget is bundled, but macOS may not list widgets from ad-hoc signed builds.

## Download and upgrade

1. Download **`iSnap-1.0.4-macOS-universal.dmg`** or **`iSnap-1.0.4-macOS-universal.zip`**.
2. Quit iSnap and replace it in **Applications**. Screenshots, settings and drafts remain in place.
3. Launch iSnap. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**.
4. Enable iSnap under **Privacy & Security → Screen & System Audio Recording** (called **Screen Recording** on some macOS versions), then quit and reopen the app if requested.
5. For automatic scrolling, enable iSnap under **Privacy & Security → Accessibility**. Allow folder access when macOS requests it for your chosen screenshot location.

Put the archives and checksum file in the same folder, then verify:

```sh
shasum -a 256 -c iSnap-1.0.4-macOS-universal-SHA256SUMS.txt
```

## Tiếng Việt — thay đổi so với 1.0.3

- Cột **Lớp và điều chỉnh mẫu** mặc định rộng tối thiểu 280 pt; kéo vạch phân cách để mở rộng. Nền các nhóm thiết lập co giãn theo cột.
- Sửa bố cục **Thư viện trống**, giữ thanh công cụ ở trên khi chưa có ảnh hoặc bộ lọc không có kết quả.
- Đưa **Thư viện ảnh chụp** ngay dưới **Hiện iSnap** trong menu.
- Đưa toàn bộ **cloud về backlog**: ẩn cài đặt, upload, lịch sử và tùy chọn trong workflow; tắt kết nối/upload tự động. Cấu hình cũ được giữ nhưng không sử dụng.
- Workflow cũ tiếp tục chụp, áp mẫu, lưu và sao chép cục bộ. Xuất ảnh và chia sẻ qua macOS vẫn hoạt động.

**Cài đặt:** thay ứng dụng trong Applications, kiểm tra quyền chụp màn hình và bật Trợ năng nếu dùng cuộn tự động. Bản phát hành chưa được Apple notarize; có thể cần **Open Anyway** hoặc cấp lại quyền sau khi cập nhật.
