# iSnap 1.0.1

This release expands iSnap's capture and editing workflow with editable projects, recovery drafts, privacy tools, a searchable Library, batch export, floating reference images, and manual scrolling capture. Settings now opens in its own popup without opening the editor.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.0.1, build 21**

## What changed since 1.0

| Area | iSnap 1.0 | iSnap 1.0.1 |
| --- | --- | --- |
| Editable documents | PNG/JPEG exports flatten the edits into an image | Save and reopen `.isnap` projects with editable annotations, crop state, original image, canvas and embedded backgrounds |
| Recovery | Editing history stays in the current session | Automatic draft saving, last-session restoration, and previous drafts preserved before switching images; a failed draft save prevents replacing the current document |
| Privacy tools | General drawing and annotation tools | Dedicated opaque redaction, blur and pixelation; on-device OCR suggests lines containing email addresses or phone numbers for you to review and select |
| Library | Recent-image grid with open, share and delete actions | Search filenames, tags and recognized text; favorites, date filters, multiple selection and bulk actions |
| Batch export | Save or export one image at a time | Export selected images with a preset or current canvas/watermark, PNG/JPEG, maximum size and filename prefix; existing files are preserved |
| Capture controls | Screen, region, window and all displays | Repeat the last selected region, a 3/5/10-second delay and optional cursor capture |
| Scrolling capture | Capture content visible in one frame | Capture a fixed region while scrolling down manually, detect overlapping content, review or adjust each seam, and export a single stitched image |
| Canvas presets | Built-in gradients and a current canvas configuration | Save and reuse named combinations of background, padding, shadow, border, ratio and watermark |
| Floating references | Recent screenshots on the Capture Line | Pin images from the editor, Library or Capture Line above other windows; resize, adjust opacity and lock position/size |
| Capture Line appearance | Classic style | Choose Classic or Cats, including cat artwork, paw clips and a running-cat animation |
| Settings | Opens as a sheet attached to the editor | One independent popup from the menu bar, gear button or `⌘,`; repeated commands focus the existing popup; Done, Escape and the close button dismiss it |

### Other improvements

- “Show iSnap” in the menu bar opens the Capture Line directly; Dock visibility follows the line's visibility.
- The annotation toolbar adapts to narrower windows with a two-row layout.
- Applying multiple suggested redactions can be undone in one step.
- Storage reporting includes projects, drafts, saved presets and imported project backgrounds.
- Vietnamese translations and the user guide cover the new features.
- The project now includes an MIT license. Binary packages include the license, third-party notices and source commit information, with a separate SHA-256 checksum file.

## Where to find the new features

- **Timer menu:** repeat-region capture, delay, cursor and scrolling capture.
- **Editor toolbar:** Redact, Blur and Pixelate.
- **… menu:** save/open projects, recent drafts, pin the edited image and suggested redactions. Save Project also uses `⌥⌘S`.
- **Canvas panel → Saved Presets:** save or apply a named style.
- **Library:** search, favorites, date filters, tags and Batch Export. Use checkboxes or Command-click for multiple selection.
- **Capture Line or Library context menu → Pin on Screen:** keep a reference image visible while working.
- **Settings → Capture Line → Line style:** choose Classic or Cats.

## Scope and behavior to know

- **Scrolling is manual and vertical.** Keep part of the previous frame visible and exclude fixed headers/scrollbars from the selected region. Repeated patterns, animation or sticky content may need manual overlap adjustment. Limits: 60,000 pixels high and 80 million output pixels.
- **Projects and drafts retain original pixels**, including content under editable redactions. Share the exported PNG/JPEG when you want to share only the rendered result. Use opaque Redact for complete coverage; blur and pixelation are visual effects. OCR suggestions are not exhaustive.
- Library OCR stays on your Mac and indexes in the background. Very small text can be missed. Tags/favorites are stored by file path and do not automatically follow external file moves or renames.
- Batch export uses the saved Library files, not unsaved editor layers. Stopping an export keeps files already completed.
- The last capture region and floating pinned windows last for the current app session. Existing settings and the screenshot Library remain in place when updating.

## Download and install

1. Download **`iSnap-1.0.1-macOS-universal.dmg`** or **`iSnap-1.0.1-macOS-universal.zip`** from the assets below. Both contain the same app for Apple Silicon and Intel.
2. Quit iSnap. Open the DMG and drag iSnap into Applications, replacing the previous copy. With the ZIP, extract it and move `iSnap.app` into Applications.
3. Launch iSnap from Applications. This build is **ad-hoc signed and not notarized**; if macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**.
4. Check **Screen & System Audio Recording / Screen Recording** permission. An ad-hoc update may require toggling iSnap's permission and restarting the app.

The widget extension is included, but macOS may not offer widgets from an ad-hoc signed build in the widget gallery.

To verify downloaded files, put the checksum file and both archives in the same directory and run:

```sh
shasum -a 256 -c iSnap-1.0.1-macOS-universal-SHA256SUMS.txt
```

## Tiếng Việt — thay đổi so với 1.0

- **Lưu dự án và khôi phục:** định dạng `.isnap` giữ từng annotation, trạng thái crop, ảnh gốc và nền; tự lưu nháp, khôi phục phiên trước và giữ bản nháp khi chuyển ảnh.
- **Che thông tin:** thêm che màu đặc, làm mờ và pixelate. OCR tại máy gợi ý dòng chứa email/số điện thoại; bạn chọn vùng cần che trước khi áp dụng.
- **Library:** tìm ảnh theo tên, thẻ hoặc chữ trong ảnh; thêm yêu thích, lọc ngày, chọn nhiều ảnh và thao tác hàng loạt.
- **Xuất hàng loạt:** áp preset/watermark, chọn PNG/JPEG, giới hạn kích thước và đặt tiền tố tên tệp; không ghi đè tệp có sẵn.
- **Chụp ảnh:** chụp lại vùng trước, hẹn giờ 3/5/10 giây, tùy chọn lấy con trỏ và chụp cuộn dọc thủ công với dò/chỉnh phần ảnh trùng.
- **Preset và ảnh ghim:** lưu nhiều mẫu khung ảnh; ghim ảnh nổi để đối chiếu, chỉnh độ trong suốt và khóa vị trí/kích thước.
- **Capture Line:** thêm giao diện Cats với hình mèo, kẹp chân mèo và mèo chạy; vẫn có thể chọn Classic.
- **Settings:** chỉ mở một popup cài đặt độc lập, không mở kèm editor; dùng từ menu, nút bánh răng hoặc `⌘,`.
- **Giao diện và tài liệu:** thanh công cụ thích ứng cửa sổ nhỏ, cập nhật tiếng Việt và hướng dẫn sử dụng.

**Lưu ý:** ảnh cuộn cần bạn tự cuộn và kiểm tra mối ghép. Project/bản nháp giữ ảnh gốc bên dưới vùng che; hãy chia sẻ PNG/JPEG đã xuất để chỉ gửi kết quả cuối. Bản phát hành chưa được Apple notarize; khi cập nhật có thể cần cấp lại quyền chụp màn hình.
